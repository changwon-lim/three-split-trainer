# 3분할 트레이너 PWA

기능
- A Push → B Pull → C Legs+Abs 자동 순환
- 세트별 중량/반복/RIR/완료 기록
- 직전 기록 표시
- 휴식 타이머
- 팔꿈치/허리 통증 체크 및 위험 운동 표시
- 체중/허리둘레 기록
- JSON 백업/복원
- 오프라인 PWA

## 사용
PWA 설치를 위해 HTTPS 또는 localhost에서 실행하세요.

로컬 테스트:
`python -m http.server 8080`

그 후 `http://localhost:8080` 접속.

휴대폰에서는 GitHub Pages, Netlify, Cloudflare Pages 같은 정적 호스팅에 폴더 내용을 올리고 브라우저의 '홈 화면에 추가/앱 설치'를 사용하면 됩니다.


## v2 추가 기능
- 설정에서 운동 추가
- 루틴별 운동 순서 위/아래 변경
- 운동 삭제
- 세트 수, 반복수, 휴식시간 수정
- 사용자 정의 루틴도 JSON 백업/복원

## v3 추가 기능
- 설정 > 운동 구성 편집에서 ☰ 손잡이를 약 0.2초 길게 눌러 드래그하면 운동 순서를 바로 변경
- 모바일 Pointer Events 기반이라 Android/iPhone/PC에서 동작
- 기존 ↑/↓ 순서 변경 버튼도 보조 기능으로 유지
- 재정렬 즉시 사용자 정의 루틴에 저장

## v4 추가 기능
- 설정 > 화면 테마에서 다크 / 라이트 / 시스템 모드 선택
- 선택한 테마를 localStorage에 저장
- 시스템 모드는 휴대폰/PC의 다크모드 설정 변화에 자동 반응
- 테마 변경 시 브라우저/PWA theme-color도 함께 변경

## v5: 상세 운동기록
- 기록 탭에서 운동 날짜를 터치하여 세트별 중량/횟수/RIR/완료 표시
- 운동별 최고 중량, 총 볼륨, 직전 같은 운동 기록 비교
- 최근 7일 운동 횟수/세트 수/운동시간 요약
- 운동별 최근 12회 최고 중량 및 볼륨 추세 그래프
- 기존 운동 기록 수정 및 개별 삭제
- 현재 저장된 localStorage/루틴/테마와 호환

주의: 볼륨(kg·회)은 완료 표시된 세트의 외부 중량×반복 수 합계입니다.
맨몸운동 및 미완료 세트는 총볼륨이 실제 부하를 온전히 나타내지 않습니다.

## v6: 운동 진행 중 종목 추가
- 운동 화면 상단의 `+ 종목` 또는 목록 하단의 `+ 운동 중에 종목 추가` 선택
- 기존 루틴에서 운동 이름을 선택하거나 자유롭게 새 운동 이름 입력
- 세트 수 / 목표 반복수 / 휴식시간 / 통증 주의 여부 지정
- **현재 운동에 추가** 버튼을 누르면 운동 중 작성한 세트 기록을 지우지 않고 바로 운동 목록에 새 카드 추가
- `앞으로도 이 루틴에 저장` 체크 시 해당 A/B/C 루틴에도 저장되어 다음번에 자동 표시
- 체크를 해제하면 **오늘 운동에만** 추가되고, 운동을 완료하면 상세 이력에 남음
- 기록 저장 포맷과 localStorage 키(`threeSplitPWA_v1`)를 유지해 v5의 운동기록 및 개인 설정과 호환


## v7: 운동 중 종목 삭제
- 각 운동 카드 아래의 `종목 삭제` 버튼으로 삭제 확인 창 열기
- `오늘 운동에서만 제외` 또는 `이 루틴에서도 삭제` 중 선택
- 입력한 중량/횟수와 완료 세트가 있다면 제거될 세트 수 안내
- 다른 운동의 세트 입력값은 화면을 재생성하지 않아 그대로 유지
- 이미 완료해 저장한 이전 세션 기록은 수정되지 않음
- 루틴에서 삭제한 운동도 `설정 > 운동 구성 편집`에서 다시 추가할 수 있음
