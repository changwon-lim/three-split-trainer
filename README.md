# 3분할 트레이너 PWA

기능
- A Push → B Pull → C Legs+Abs 자동 순환
- 세트별 중량/반복/RIR/완료 기록
- 직전 기록 표시
- 휴식 타이머
- 팔꿈치/허리 통증 체크 및 위험 운동 표시
- 체중/허리둘레 기록
- JSON 백업/복원
- 오프라인 PWA

## 사용
PWA 설치를 위해 HTTPS 또는 localhost에서 실행하세요.

로컬 테스트:
`python -m http.server 8080`

그 후 `http://localhost:8080` 접속.

휴대폰에서는 GitHub Pages, Netlify, Cloudflare Pages 같은 정적 호스팅에 폴더 내용을 올리고 브라우저의 '홈 화면에 추가/앱 설치'를 사용하면 됩니다.


## v2 추가 기능
- 설정에서 운동 추가
- 루틴별 운동 순서 위/아래 변경
- 운동 삭제
- 세트 수, 반복수, 휴식시간 수정
- 사용자 정의 루틴도 JSON 백업/복원

## v3 추가 기능
- 설정 > 운동 구성 편집에서 ☰ 손잡이를 약 0.2초 길게 눌러 드래그하면 운동 순서를 바로 변경
- 모바일 Pointer Events 기반이라 Android/iPhone/PC에서 동작
- 기존 ↑/↓ 순서 변경 버튼도 보조 기능으로 유지
- 재정렬 즉시 사용자 정의 루틴에 저장

## v4 추가 기능
- 설정 > 화면 테마에서 다크 / 라이트 / 시스템 모드 선택
- 선택한 테마를 localStorage에 저장
- 시스템 모드는 휴대폰/PC의 다크모드 설정 변화에 자동 반응
- 테마 변경 시 브라우저/PWA theme-color도 함께 변경
